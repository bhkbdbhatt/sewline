# Sewline Website

Marketing and sponsorship website for the Sewline project. Designed to be deployed on Netlify, Vercel, GitHub Pages, or any static hosting platform.

## Features

- Modern, dark-themed responsive design
- Hero section highlighting key features
- Feature grid showcasing capabilities
- Compliance standards badges
- Sponsorship section with multiple platforms
- Mobile-responsive navigation
- Optimized for static hosting

## Local Development

Simply open index.html in your browser, or use a local server:

`ash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve .
`

## Deployment

### Netlify
1. Drag and drop the website folder to [Netlify Drop](https://app.netlify.com/drop)
2. Or connect your Git repo and set publish directory to website

### Vercel
1. Install Vercel CLI: 
pm i -g vercel
2. Run ercel from the website directory

### GitHub Pages
1. Push to GitHub
2. Go to Settings > Pages
3. Set source to deploy from branch and select /website folder

- CSS3 (Custom properties, Flexbox, Grid)
